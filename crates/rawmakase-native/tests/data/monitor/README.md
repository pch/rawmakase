Synthetic monitor profiles and Little CMS 2.19's transforms of sRGB to them, for
`color_management`'s tests: relative colorimetric with black-point compensation,
over the 18-level grid 0, 15 … 255 (red slowest). `.lcms8` is Little CMS's 8-bit
result, `.lcms16` its floating-point result as 16-bit values. The profiles were
made with Little CMS from invented primaries and curves (Display P3 and Adobe RGB
like matrix/TRC profiles, a matrix/TRC profile with a raised black, and LUT-based
display profiles with raised blacks, with only perceptual tables or with
colorimetric ones too); no third-party profile is included.
